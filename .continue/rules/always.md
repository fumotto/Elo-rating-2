# General Coding Rules

## Language

- すべて日本語で回答する
- ソースコード中のコメントは日本語で記述する
- エラーメッセージの説明は初心者にも分かるように説明する

## Code Quality

- 可読性を最優先する
- DRYを意識する
- KISSを守る
- YAGNIを守る

## Naming

- 略語を多用しない
- 意味が分かる名前を付ける

## Before Coding

実装前に

- 実装方針
- 影響範囲
- リスク

を簡潔に説明する。
