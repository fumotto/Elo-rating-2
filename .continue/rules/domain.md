作りたいウェブアプリについての説明をします。
まず、やりたいこととしてはイロレーティングによる3対3のチーム戦マッチの対戦管理です。
下記のソースコードの発展版です。
https://github.com/fumotto/Elo-rating

フロントとしてはVite+Reactを利用。
デプロイに関しては引き続きGitHub Pagesの機能を用いて 単純なページとして紹介します。

バックエンドとしてはsupabaseを利用して
・ログイン認証（Discordアカウントでのログイン）
・ログインユーザのロール割り当て
  - Admin_user
    * supabaseサーバーの起動
    * 選手の登録・名前変更
    * 戦績の登録・ロールバック
    * ランキング表示
    * 戦績履歴表示
    * ランクリセット
  - Nomal_user（選手）
    * 戦績の登録
    * ランキング表示
    * 戦績履歴表示
  - Guest_user
    * ランキング表示
    * 戦績履歴表示
・登録内容はRDBで管理

Discordアカウントとログインユーザは1対1で紐づきます。
ログインユーザはSteamIDかPlaystationIDのいずれか片方を必ず持ち、一意です。どちらのIDかは区別がつくようにしたい。
ログインユーザの名前は変更可能です。

フロントエンド(viteフォルダ配下)とバックエンド(supabaseフォルダ配下)を両方コードで管理。
またdocs配下にコード要約したプロジェクトドキュメントを配置。
プロジェクトドキュメントはMarkdownの文章とMermaid記法の図で構成する。

本番はmainブランチを利用。
開発はdevブランチを利用。

GitHub Actionsを利用して
プルリクエストが発行されたタイミングでテストを行い、
マージされたタイミングで本番環境(Github Pagesとsupabase)にデプロイする。
プロジェクトドキュメントも生成する。
