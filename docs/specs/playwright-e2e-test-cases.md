# Playwright E2E テストケース一覧

## 前提

この一覧は、[guest-user-manual](../manuals/guest-user-manual.md)、[player-user-manual](../manuals/player-user-manual.md)、[admin-user-manual](../manuals/admin-user-manual.md) をもとにした正常系・異常系のテストケースです。境界値テストは含めません。

## 正常系

| ID     | 役割   | テスト名                               | 期待結果                                                      |
| ------ | ------ | -------------------------------------- | ------------------------------------------------------------- |
| TC-G01 | ゲスト | ホーム画面を開いて権限を確認できる     | ゲストとして閲覧可能なメッセージが表示される                  |
| TC-G02 | ゲスト | ランキングを表示できる                 | 選手のランキング一覧が表示される                              |
| TC-G03 | ゲスト | ランキングを名前で検索できる           | 検索語に一致する選手のみ表示される                            |
| TC-G04 | ゲスト | 戦績履歴を表示できる                   | 試合一覧が表示され、詳細を展開できる                          |
| TC-P01 | 選手   | Discord ログイン後にロールを確認できる | ホーム画面に選手または管理者として表示される                  |
| TC-P02 | 選手   | 戦績登録フォームを送信できる           | 6人の選手が選択されている状態で登録成功メッセージが表示される |
| TC-P03 | 選手   | OCR JSON を貼り付けて反映できる        | 勝者・敗者の選択肢が自動で埋められる                          |
| TC-A01 | 管理者 | 管理ページへアクセスできる             | 管理者専用の管理コンテンツが表示される                        |
| TC-A02 | 管理者 | K 係数を更新できる                     | 保存成功メッセージが表示される                                |
| TC-A03 | 管理者 | 新規選手を追加できる                   | 選手一覧に追加された選手が表示される                          |
| TC-A04 | 管理者 | 選手情報を編集できる                   | 更新成功メッセージが表示され、一覧に反映される                |
| TC-A05 | 管理者 | ユーザーロールを変更できる             | 変更後のロールが一覧に反映される                              |

## 異常系

| ID     | 役割   | テスト名                         | 期待結果                                     |
| ------ | ------ | -------------------------------- | -------------------------------------------- |
| TC-E01 | ゲスト | 管理ページへ直接アクセスする     | 管理者専用ページの制限メッセージが表示される |
| TC-E02 | ゲスト | 戦績登録ページへ直接アクセスする | 戦績登録に必要な権限のメッセージが表示される |
| TC-E03 | ゲスト | 存在しないページへアクセスする   | ホームへリダイレクトされる                   |
| TC-E04 | 選手   | 未入力のまま戦績登録を送信する   | 入力不足に関するエラーメッセージが表示される |
| TC-E05 | 管理者 | 不正なロール変更操作を試みる     | 失敗理由が明示される、または変更されない     |

## 実装時の優先順位

1. ゲスト系の閲覧フロー
2. 権限制御の異常系
3. 選手系の戦績登録フロー
4. 管理者系の管理操作フロー
